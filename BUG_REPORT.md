## Not bugs (verified, do not "fix")
- Contact honeypot returns 200 without storing: intentional silent accept for bots (public.js). The message is never stored or emailed.
- Unknown /team/* and /projects/* return HTTP 200: intentional Netlify rewrite to a sample detail shell; the client then fetches the real slug and shows the error state. Top-level unknown paths still 404.
- Upload-sign returns 503 without Cloudinary env: intentional fail-closed behaviour (upload_unavailable), not a missing feature.
- Live public lists are empty and /api/site is null: the live Firestore has no real content yet, not a data-loss bug.
- Sample slugs (sample-ayesha-khan etc.) return "Member not found" on live: sample data exists only in demo mode, by design.
